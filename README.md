## About Me

I'm a Software Engineering student with a focus on web development, backend systems, and the infrastructure that supports them.

Most of my projects involve some combination of programming, databases, Linux, networking, servers, or automation. I'm also interested in cybersecurity and cloud infrastructure, and I've been learning more about technologies such as Docker, Kubernetes, and AWS.

Outside of web development, I work on IoT projects with ESP32 and Node-RED and occasionally build games with GameMaker. I also like running and managing my own servers, which has given me a lot of hands-on experience with Linux, networking, services, and troubleshooting.

I'm generally more interested in understanding how the whole system fits together than sticking to a single technology or stack.
